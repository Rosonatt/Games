# Games Repository

This repository contains simple game projects developed using Python. Each game is designed to help explore programming concepts and improve coding skills.

## 📁 Repository Structure

- **Adventure_Text/**: A text-based adventure game that explores interactive storytelling.
- **flappt bird/**: A Python version of the classic Flappy Bird game.
- **nave/**: A space shooter game with basic mechanics.
- **snake/**: The classic Snake game implemented in Python.

## 🚀 Technologies Used

- **Python**: All games in this repository are implemented using Python, leveraging its simplicity and flexibility for game development.

## 🎯 Objectives

- Practice Python programming through game development.
- Explore concepts such as user input handling, game loops, and basic AI.
- Provide fun and engaging projects for beginners and enthusiasts.
